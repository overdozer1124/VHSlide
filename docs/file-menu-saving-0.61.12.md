# 保存操作をファイルメニューへ集約 — v0.61.12

2026-10-30（日本時間）。ユーザーから「保存ボタンは必要なく、ファイルに集約されている」と指摘を受け、独立した保存ボタンを削除した。

- ヘッダーは単独の「ファイル」ボタンとし、分割ボタン用の片側だけ角丸・境界線なしのスタイルも解除。
- JSON・PDF・完全バックアップ／復元・保存した版は、既存のファイルメニューから利用する。
- 以前の「JSONの1クリック保存を維持する」という要望は、今回の明示指示で更新された。AGENTS.mdにも最新要件を追記。
- 既存試験の保存操作をファイル→JSONの経路へ更新。保存データ・Undo・読み込み・閲覧専用ゲストの権限の検査は維持。
- アプリの保存形式、データベース、共有認可、Cloudflareのvars／migrations／プランは変更しない。
