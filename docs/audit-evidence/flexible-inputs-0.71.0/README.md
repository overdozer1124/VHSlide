# 0.71.0 検証記録

対象：自由配置の回答欄、自動保存、明示的に公開する回答スライド。機能と利用手順は [設計・利用説明](../../design/free-worksheet-inputs.md) を参照。

- 単体テスト196件、Node API21件、Cloudflare API27件が成功。
- Nodeのタッチ端末向けアンケート・ワークシート・自由配置の9フローが成功。デスクトップの従来アンケート3フロー、新規・既存ワークシート6フローも成功。
- 最終版のCloudflare実行環境で、新しい入力欄の作成・透明背景・枠なし・項目名非表示、入力停止／フォーカス移動／日本語変換後の自動保存、未送信入力の再読み込み復旧、匿名共有・自動更新・停止、拡大・2件比較、独立した項目の複製、回答を含まない配置ひな形の再利用を、デスクトップ・タッチの両方で確認。
- 最終API検証では、項目単位の更新統合、権限、既存回答を保持する項目追加、プレビュー非公開、選択した回答だけの公開、公開データからのメール・内部ID・スライドが参照しない項目の除外、スナップショットと自動更新の違い、共有停止、再起動後の保持、新しい回答者の追加後も匿名ID・匿名の表示番号が維持されることをNode／Cloudflareで確認。
- 空のアンケート回答を自動保存で取り消せることもNode／Cloudflareで確認。空の古い送信形式の検証は維持。
- 最終ビルドをCloudflare本番へ `wrangler deploy --keep-vars` で反映。既存の設定・認証変数を保持。
- 本番URLでPPTX取込・JSON出力・復元、共通モーダルの入口・キーボード操作、持ち運び用のフォーム定義の表示をデスクトップ・タッチ計10件で確認。テストには合成教材だけを使い、実際の利用者のアカウント・作品は使用していない。
- 本番のヘルスチェック、ログインなしの回答スライドAPIの401拒否、配信アセット5件のSHA-256とローカル最終ビルドの一致を確認。

`verification.json` に最終ソースコミット・デプロイID・配信ファイルのハッシュを記録。`build.log` のバンドルサイズ注意は既存のVite警告で、ビルドは成功。初期の同時検証で生じた環境起動待ちのタイムアウトは、ビルド完了後の最終Cloudflareブラウザ検証で解消した。新規フローは既存の複数操作を含むため、シナリオ全体の上限を180秒、5秒間隔のワークシート取得を待つ入力有効化だけを10秒に設定した。
