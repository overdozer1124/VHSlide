# ツールバーのフォームへの入口一本化（0.71.3）

編集ツールバーの「回答欄を追加」を「フォーム」に変更し、右下の独立した入口を削除した。マップ・編集・発表・ホスト追従の各ツールバーから共通画面を開き、前回のタブを表示する。閲覧専用の参加者も利用できる。追従中は背景編集を引き続き禁止し、フォーム内の回答操作を許可する。フォームを開いたまま追従が終わってもフォーカスを背景へ移さない。

検証：

- ビルドと単体52件が成功。
- Cloudflare実行環境のデスクトップ・タッチ計18件が成功。フォーム作成、モーダル統合、入力・自動保存・CSV・集計グラフ・回答共有を確認。発表・追従中のフォーム操作と、フォームを開いたまま追従が終わる場合のフォーカス維持も確認。
- 追従ロックの追加6件が成功。背景のページ移動・編集・追従終了を拒否し、元の編集内容・選択・カーソルと日本語変換の確定を維持することを確認。
- 静的プレビュー10件が成功。旧ボタンなし、フォーム入口1つ、共通モーダルID、キーボード操作と焦点復帰を確認。APIサーバーなしの端末利用テストのため、プレビューのAPI接続拒否ログは想定内。
- 本番デプロイ後のデスクトップ・タッチ12件が成功。入口の表示・削除、モーダル、持ち運び用フォーム、PPTXの取込・保存・復元を確認。実際のアカウント・作品は使わず、合成教材で検証。
- 本番HTMLとアセット5件がローカル最終ビルドと一致し、ヘルスチェックも成功。デプロイID・ソースコミット・ハッシュは `verification.json` に記録。

既存の認証変数・データ形式・サーバー側の編集権限判定は変更していない。
