# 回答欄の作成操作改善（0.71.1）

ページ編集ツールバーの「文字」の隣に「回答欄を追加」を置き、サイドバーの作成入口を専用ダイアログへ移動。新規／既存項目の利用を分け、新規時は項目名・回答形式・プレビューを中心に表示する。保存先の詳細は折りたたみ、形式は説明付きカードから選ぶ。追加後は画面を閉じ、移動・サイズ調整を案内する。

- 単体テスト3件：入力欄定義の互換性・更新履歴とバージョンの一致。
- Cloudflare実行環境のデスクトップ／タッチプロファイル計2フロー：新規の初期選択、必須入力、既存項目がない時の案内、形式と項目名のプレビュー、Escapeとフォーカス復帰、入力途中の保持、処理中の閉じる操作抑止、追加後の案内、従来の自動保存・未送信入力の再読み込み復旧・共有・比較・複製・配置ひな形。
- 最終ビルドの入口テスト2件：入口が画像ボタンより前にあり、作成画面が中央に表示され、ローカル利用時はクラウド共有の必要性を案内し、Escapeで入口へフォーカスが戻ること。静的プレビューではAPIサーバーを立てないため、`preview-entry.log` の `/api/config` 接続拒否は端末利用へのフォールバックを確認する条件。
- 本番デプロイ後のデスクトップ／タッチ計12件：新しい入口・中央表示・フォーカス、共通モーダル、持ち運び用フォーム定義、PPTX取込・出力・復元を確認。
- 本番のヘルスチェックと配信アセット5件のSHA-256がローカル最終ビルドと一致。

ソースコミット、デプロイID、配信ファイルのハッシュは `verification.json` に記録。実アカウントや実際の作品はテストに使わず、合成データと隔離した認証環境で確認した。バックエンドの保存形式・権限判定は変更していない。
