# クラウド作品一覧の保管・復旧操作 — v0.61.6

2026-10-30（日本時間）。[再配置計画](ui-relocation-plan.md)の2.4節の残項目。

## 変更

- 作品一覧の「その他」に「ごみ箱を開く」「バックアップと復元」を集約。検索・作品カード・共有管理・容量の説明は既存の位置と動作を維持。
- `src/CloudPanel.tsx`：通常の保管・復旧欄は畳む。BackupPanelは常にマウントし、一覧取得・処理・ファイル入力を止めない。ごみ箱も非表示時にアンマウントしない。
- `src/BackupPanel.tsx`：折りたたみは作品一覧でのみ有効。未完了ジョブ・確認済みファイル・復元内容の確認・処理中・メッセージ・ジョブ取得エラーは優先し、その他を開かなくても表示。ヘッダー保存メニューの独立したバックアップ画面では、従来どおり通常表示。
- 未完了ジョブの取得失敗を黙って隠さず、案内と再確認ボタンを表示。成功して未完了ジョブがなければ通常の一覧へ戻し、その他へフォーカスを戻す。
- `src/ActionMenu.tsx`：ポータルの配置先を任意指定できるようにし、クラウドのメニューをモーダル内部へ配置。スクロール領域の見切れと、モーダル外へキーボード操作が出る問題を避ける。既存メニューは既定の配置を維持。
- `src/CloudTrash.tsx`：開いた時に見出しへフォーカスできるようにした。保存・復元・取消・共有権限のAPIや状態遷移は変更していない。
- `src/style.css`：見出し・その他・非表示時のレイアウトを調整。バージョン・更新履歴は0.61.6。
