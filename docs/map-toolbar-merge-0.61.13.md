# 全体マップのツールバー統合 — v0.61.13

2026-10-30（日本時間）。ユーザーの要望により、全体マップの操作を上段の全体マップ／ページ編集・履歴のツールバーへ統合し、サムネイルの表示領域を広げる。

- 常設の操作列を44pxの1段に統合。重複した全体マップの見出しを削除し、対象シート・ページ数は残す。
- フィルタ、複数選択、行列の一括操作、ページ番号検索、縮小・倍率・拡大、表示設定、Undo／Redo、その他の入口は維持。
- 狭い画面では統合した操作列の中で横スクロールする。ページ全体を横に広げない。
- MapViewの状態は維持し、操作列だけを上段のスロットへReact Portalで表示。編集からマップへ戻るときの選択・倍率・スクロール位置を維持する。移した操作列でもCtrl＋ホイールによるブラウザ全体のズームを防ぐ。
- フィルタ後の均等な格子と上下左右の発表、共有権限、保存形式、ファイルメニューへの保存集約は維持。

## 検証

- ビルド、更新履歴・バージョンの単体試験、Cloudflare型チェック・dry-runが成功。既存のバンドルサイズ警告あり。
- 通常画面の関連54件を実行し、44成功、既存の端末条件による10skip。PC／タッチ、1366／1024／810／390pxを含む。フィルタ、比較、選択、一括操作、表示パネル、倍率、ピンチ、編集との往復、400枚マップを検査。
- 統合先に操作列が1つだけ存在し、マップパネル内には操作列が残らないこと、操作列が1段で、その直下からマップ領域が始まることを既存画面試験に追加した。
- 公開前のv0.61.12を、1366×768pxのブラウザ内400枚サンプルで測定：マップ領域はy=139px、高さ554px。上段36px、下段44px。
