# 自由配置の回答欄（0.71.3）

固定の教材テンプレートに依存せず、通常のスライド編集に入力欄を組み合わせる機能を実装しました。従来のフォーム一括配置・回答一覧・CSV保存も利用できます。

## 作成

共有作品のホストがツールバーの「フォーム」を開きます。共通モーダルの「回答欄を追加」タブで、設定とプレビューを確認しながら、「新しく作る」か「作成済みの項目を使う」を選びます。保存先の詳細は折りたたんで表示し、新規作成では項目名と回答形式を中心に設定できます。新規項目を作成するか、既存のワークシート項目／アンケートを選び、「スライドに追加」を押します。記述・チェック・単一選択・複数選択を扱えます（アンケートではチェック単体は複数選択になります）。入力欄以外をドラッグして移動し、通常のハンドルでサイズを変更します。文字・画像・図形と組み合わせ、整列・グループ化できます。

選択した入力欄では、項目名の表示、文字サイズ・文字色、透明背景、背景色、枠線を設定できます。問いを通常のテキストとして別に配置すれば、入力欄側の項目名を非表示にできます。通常の複製は同じ回答項目を参照します。「別の回答項目として複製」は独立した新しい項目を作ります。

ページの入力欄を「配置ひな形」に保存できます。ひな形は端末・アカウント別のローカル保存で、回答を含みません。使用時は新しいワークシートと項目を作り、同じ位置・サイズ・装飾で配置します。ワークシートは1件40項目・1作品30件、回答は500人までです。

## 自動保存

記述は入力停止から約1秒後、または欄からフォーカスを外した時に保存します。選択・チェックはすぐ保存します。日本語の変換中は送信を待ちます。項目単位の更新をサーバーで統合するため、複数の自由配置欄からの保存で別の項目を消しません。

通信失敗時は未送信の値を端末に残し、通信復帰・再試行で送ります。保存中・未保存・保存済みを画面下部に表示します。認証・受付終了などのエラーでは未保存と理由を示し、手動で再試行できます。端末保存が使えない環境では再読み込み前の復旧保証はありません。共有作品・アカウント別に送信待ちを分離し、アカウント切替後に前のアカウントの入力を送信しません。

## 回答スライド

「ユーザーフォーム」の「回答スライド」タブで、ホストはフォームがあるスライドのサムネイルを選び、各参加者の回答をプレビューできます。プレビューはホストだけに表示され、比較や拡大もできます。

ホストはスライドごとに全員／選択した回答、匿名／氏名表示、共有時点で固定／自動更新を選び、「選択したスライドの回答を全員に共有」を押します。これを繰り返して最大50枚を共有でき、各スライドの共有を個別に停止できます。自動更新で全員を選ぶと、後から保存された回答も含みます。

参加者は「回答スライド」の「共有された回答を開く」から専用の一覧画面へ移動します。共有されたスライドを選択し、一覧の倍率を変更できます。回答をクリックすると閲覧専用のスライドが開き、左側の一覧からほかの回答へ切り替えられます。一覧は24件ずつ表示し、共有状態と自動更新の回答を約3秒ごとに取得します。

レイアウトは共有時点で固定されます。入力欄の配置を変えた場合は再共有してください。公開データは、そのスライドの入力欄が参照する項目に限定します。メールアドレスは公開せず、匿名時は氏名・内部アカウントIDも公開しません。参加権限のないアカウントは取得できません。CSVの全項目・個人情報は従来どおりホスト用です。

スライドJSONには入力欄の定義と参照だけを保存します。回答は本文へ書き込まず、クラウドのアカウント別データとして扱います。別の共有作品へインポートした参照は、元の作品として回答できません。新しい項目を作成するか、配置ひな形を使用してください。
