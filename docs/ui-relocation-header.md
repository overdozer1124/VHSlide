# UI再配置 Step 5（前倒し）— v0.61.2

対象：[UI再配置計画](ui-relocation-plan.md)。2026-10-29。

## 実装した範囲

- 「新しく／開く／クラウド」は文字付き「作品」メニューに集約。各入口は計画上許容された1クリック増。新規作成時のクラウド離脱・未保存保護、JSON読み込み前の退避、クラウド作品一覧の更新は既存ハンドラーを維持。
- 集合ボタンを共通のUndo／Redo列から切り離し、発表の右隣へ移動。集合の開始／終了は引き続き1クリック。ホスト限定・接続状態・無効条件・通知・同期処理は変更していない。
- 表示範囲とページ追加方法をホスト専用の「ゲストの設定」にまとめる。ネイティブselectを含む独立した設定パネルであり、矢印キーを横取りするActionMenu内には入れない。Escで閉じて入口へ戻る。外側クリック・フォーカス離脱でも閉じる。
- 保存・発表の分割ボタンは維持。ノート付き発表の別窓をクリック処理内で開く方式も維持。
- 作品タイトルと保存状態を縦にまとめ、小画面でも保存状態を表示。クラウドの役割・参加人数も保持。最小幅付近では長い状態名は省略表示されるが、状態アイコン・titleによる全文は保持。
- データ形式・共同編集・権限認可・サーバーコード・Cloudflare設定は今回変更していない。
- 既存のクラウド／新規作成テストは、操作と検証内容を保ったまま「作品」メニュー経由へ変更した。
