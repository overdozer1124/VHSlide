## 実装範囲

- `src/MapView.tsx`：シート全体の「行・列を一括操作」を、ホスト専用のマップの「その他」に移動。ページ選択なしでも利用可能。既存のMapBatchPanel・追加削除ハンドラーを再利用し、フィルタ外も含むシート全体が対象である説明を維持。
- 比較は選択モード中の操作帯へ移動。0〜1枚は案内付きで無効、2〜4枚は実行可能、5枚以上は「4ページ以下に減らしてください」と表示して無効。選択は勝手に切り捨てない。
- `src/App.tsx`：選択IDをそのまま既存SlideActionDialogのinitialIdsへ渡す。2〜4枚という呼出し条件も確認。
- `src/SlideActionDialog.tsx`：有効な初期選択がある比較は、そのまま比較表示で開く。既存の描画・候補範囲・選び直し・最大4枚制限を再利用。範囲外・削除済みのページは従来どおり除外し、2枚未満なら比較画面として成立させない。
- 比較から閉じると選択状態を維持し、比較ボタンにフォーカスを戻す既存の仕組みを利用。メニューのEscはページ選択の解除へ伝播しない。
- `src/ActionMenu.tsx`：表示文字の任意指定を追加。「その他」という短い表示と「マップのその他」というアクセシブル名を併用し、アプリ全体のその他と区別する。従来のメニューは既定動作のまま。
- 直接の縮小／倍率／拡大、選択ページのフィルタ・削除、ピンチ遷移を維持。データ形式、共同編集、権限認可、安定した行・列ID、発表ルートは変更していない。
