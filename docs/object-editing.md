# 0.41.0：オブジェクト編集 第1段階

## 操作の設計

「入れる → 選ぶ → 整える」を共通化する。挿入はツールバー、選んだ対象の設定は右側、細かな変形は「サイズ・向き」に置く。既存のスライド移動ジェスチャーは維持し、オブジェクト移動は枠から行う。

- 図形：基本・矢印・吹き出し・フローの4分類、25種類。図形をクリックして直接文字入力。旧作品の文字を持たない図形は「図形に文字を入れる」で追加できる。
- 線：直線・矢印・両矢印・折れ線・曲線。両端の丸をドラッグして向きを変更。端点形状、線幅、実線／破線／点線を設定できる。オブジェクトへ自動追従するコネクタではない。
- 複数選択：Shiftクリック、または「まとめて選択」をオンにしてタップ。選択を終えたら同じボタンで終了し、選んだ枠をドラッグしてまとめて移動。通常の1本指によるページ移動と区別する。
- 配置：1個ならスライド基準、複数なら選択範囲基準で整列。等間隔は3個以上、かつ両端の間に重ならず収まる場合に有効。
- 複製・削除・移動・整列は選択全体を1回の作品変更として確定。共同編集では既存の本人Undoを使用する。
- 変形：90度単位の回転、上下／左右反転、縦横比固定、位置・サイズの数値指定、不透明度。回転して収まらないときは比率を保って縮小してスライド内へ収める（最小寸法20pxを下回る極端に細い要素は20pxに補正）。自由角度回転、永続グループは今回の対象外。

## データ・互換性・認可

`src/model.ts` が既存のversion 1形式に任意フィールドを追加し、既存JSONを引き続き読める。`shapeCatalog.ts` に固定SVGパスを保持し、入力データに任意SVG／HTMLを許さない。`line` の端点は枠内0〜100の座標。回転・反転は線の場合には端点へ反映する。図形ラベルは `sharedDeck.ts` のY.Textで同期する。

`Canvas.tsx` を全体マップ、編集、発表、比較、PDF印刷で共用する。変形された見た目の外接矩形を移動・リサイズの枠とし、重なり順は既存の要素配列順を維持する。

共同編集プロトコルを3へ更新。古い画面から新要素を誤って削除・書き換えることを防ぐため、Node／Cloudflareの両方で旧プロトコルの更新を拒否する。旧キャッシュに未送信変更がある場合の読み取り専用・JSON救出は従来の仕組みを維持する。新しい要素を含むJSON／ZIPを古いアプリへ取り込めるという意味の前方互換性はない。

編集権限は従来どおりスライド単位でサーバー検証する。行・列の安定ID、バックアップのリビジョン検証・復元ジョブ、非公開画像と招待承認の仕様は変更しない。依存パッケージの追加なし。

`tests/cloud/objects.spec.ts`：独立したテスト作品と合成アカウントで、2端末の図形ラベル・変形・線の同期、本人Undo、閲覧権限による挿入停止をNode／Cloudflareで確認する。

実機Chromebook／iPadのペン・日本語IME、支援技術での操作は未確認。公開ルーム・本番作品は検証に使用しない。実行結果は後述の検証記録に追記する。
