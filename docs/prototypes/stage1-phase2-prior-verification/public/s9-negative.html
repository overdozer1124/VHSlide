先行実測の参照範囲と未実証のもの

  • Cookie返送：S9 正常系の実施記録（Codex seq 632/634：GET /nonce 200、 POST /admin/verify-only 200 ok）で実証済みです。ctx が一致しなければ 403 nonce_context_mismatch になるため、200 ok は Cookie が返送され ctx が一致した ことの実証です。本画面は Cookie の有無を読み取らず、no-cookie ステップは credentials: "omit" で送らない対照とし、応答の理由コード（nonce_context_mismatch） でのみ判定します。
  • Cookie属性：属性値そのもの（Secure / HttpOnly / SameSite=Strict）の 実環境での実測元はありません。実環境の Set-Cookie ヘッダー値は記録されていないため、 実環境では未確認です。根拠はソース（両ビルドの /nonce が verify 構成で Secure を 付ける箇所）とローカル試験だけであり、本画面では属性値を読み取らず表示もしません。 属性値を実測したものとして扱いません。
  • 実 Google nonce 一致：捕捉したトークンの nonce と /nonce で発行した nonce の一致は、 PC 内署名検証（verifyIdTokenLocal）の expectedNonce 照合で真偽だけ確認します。nonce の値 そのものは表示・ログに出しません。
  • 未実証（本画面の対象外）：実トークン期限切れ（T3 は未実施）、異なる aud／iss、 tokeninfo 到達不能。
  • Origin の境界：Origin はページ自身の生成元であり、画面からは変えられません。 Origin 試験はこの画面の対象外です。Origin の対照は、秘密なしの2要求（正しい生成元／誤った 生成元）が指定経路と想定した判定層に届くことを、画面ではなく秘密なし curl 対で事前に確認します。
