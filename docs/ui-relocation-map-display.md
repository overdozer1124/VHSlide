# マップ表示設定の集約 — v0.61.5

2026-10-29。[UI再配置計画](ui-relocation-plan.md)に残っていた表示パネルの整理。

## 実装

- `src/MapView.tsx`：直接の縮小／倍率／拡大を残し、番号一覧・いまのページ・横をおさめる・行の名前・倍率のステップ設定を「表示」へ移動。
- `src/MapDisplaySettings.tsx`：既存のポータルパレットを再利用し、通常のフォーム操作ができる表示パネルを追加。番号切替・現在ページ・横幅調整を選ぶと閉じる。表示する関数・ズーム計算は既存のまま。
- `src/MapZoomSettings.tsx`：既存の倍率入力・プリセット・検証を、パネル内へ埋め込めるようにした。メニュー項目の矢印操作と競合するrole=menuの中には入力欄を置かない。適用後は表示パネルを閉じて入口へ戻る。未適用の変更はパネルを閉じると破棄し、元の設定を維持する。
- `src/ObjectPalette.tsx`：入力フォーム等によってパネルが伸びたときも画面内に収まるよう、開いているパネル1つだけをResizeObserverで監視。閉じる時に監視を解除する。既存の図形・線・編集画面の表示設定でも利用する共通部品のため、既存の編集ツールの回帰試験も実施。
- 行の名前は従来どおり、クラウド作品かつ非フィルタ時に表示し、ホストのみ変更可能。ゲストには無効な状態で表示。フィルタ・編集権限・保存形式・同期処理は変更していない。
- マップから離れたらマップ用のポータルUIを閉じる。表示パネルを開いてキーボード操作／ピンチで編集へ切り替えても、編集画面に残さない。
- 既存テストの入口を「表示」経由へ変更し、元の検証内容は維持。行見出しの共有テストで使うクラウドの入口も、前段階の作品メニュー経由へ合わせた。
