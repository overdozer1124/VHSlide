# オブジェクト編集の段階的な拡張

方針：Googleスライドの画面をコピーせず、児童・生徒が「入れる→選ぶ→整える」を迷わず操作できることを優先する。従来の格子状スライド、内容上のスワイプ、枠からの移動、直接入力を維持する。

## 第1段階：共通操作と基本表現（0.41.0）

- Shiftクリックと「まとめて選択」による複数選択、一括移動・複製・削除。
- 配置・均等配置、90度単位の回転、反転、縦横比固定、段階的な前後移動。
- 基本・矢印・吹き出し・フローの図形パレット、図形内の文字、塗りなし・線幅・破線。
- 線・両端の矢印・折れ線・曲線と端点操作。
- 選択数と対象に応じて設定を切り替える。高度な変形は展開式にし、ツールバーを増段しない。
- 既存データ、共同編集・権限・本人Undo・JSON・ZIP・履歴・PDFでの保持を検証する。

第1段階を実装し、単体・Node・Cloudflare・ブラウザーの対象試験で検証。[操作と検証結果](object-editing.md)。第2段階は下記のとおり実装し、第3段階も実装し、検証範囲は下記の記録に記載。

## 第2段階：写真・文章・表（0.42.0）

画像のトリミング／差し替え／代替テキスト、文字範囲の書式と段落、表の指定位置への行列操作・セル書式・列幅／行高・TSV貼り付けを実装。JSON／ZIP version 1と範囲別権限を維持し、文字と書式をY.Textへ統合。[操作・設計・検証記録](content-editing.md)。

## 第3段階：情報の構造化（0.43.0）

グループ、追従コネクタ、比較・手順・時系列のテンプレート、作品内リンク、基本グラフ。複製時の参照先ID、同時構造変更、端末の応答性を検証する。[操作・設計・検証記録](structure-editing.md)。

## 利用条件を整理してから検討

音声・動画保存、Google Drive等との連携、外部素材検索、AI。保存容量、外部送信、学校の接続制限、無料提供の運用方針を確認してから仕様を決める。
