# ヘッダー・マップ・サイドバーの再配置 — v0.61.10

2026-10-30（日本時間）。利用者の実画面での指摘を反映。従来の再配置案の頻度分類より、今回の具体的な要望を優先した。

## 反映内容

- 全体マップの「その他」を削除。「行・列を一括操作」を直接押せるボタンに戻した。更新履歴・使い方の「その他」はナビゲーション側の1つを残す。
- 「作品」メニューを「ファイル」へ変更し、新規・開く・JSON／PDF・バックアップ／復元・保存した版を集約。「クラウド」は独立した直接ボタンへ。ファイルの隣には1クリックのJSON保存を行う「保存」を残した。
- 発表の分割ボタンを、集合・ゲスト設定の後ろへ移動。視覚上だけでなくDOMとTab移動順でも最後にした。ノート付き発表・保存済みルート等の起動処理は維持。
- 全体マップのツールバーを44pxの1行に固定。幅が足りない場合はツールバー内の横スクロールを使い、ページ全体を横へ広げない。通常の縮小・倍率・拡大と、表示パネルへの入口は維持。
- 手描きにPencilのアイコンを追加。
- 左の折りたたみボタンはページ一覧の見出し、右は編集設定パネルの見出しへ移動。たたんだ後は各側の36pxの細いタブから戻せる。切替後のフォーカスも新しいボタンへ移す。選択中のオブジェクト、既存のパネル設定の保存仕様は変更しない。
- 760px以下の小さい画面ではヘッダーを2段にして、ファイル・クラウド・発表を隠さない。ホスト用操作などで収まらない場合は操作列を横スクロールできる。マップのツールバーはこの場合も1行。

## 実装

`src/App.tsx`、`src/MapView.tsx`、`src/Editor.tsx`、`src/SlideRail.tsx`、`src/EditorInspector.tsx`、`src/style.css`。更新履歴・package／lockのバージョンは0.61.10。

権限、行列ID、同期、保存形式、発表範囲、ゲストのページ追加条件は変更していない。サイドバーのボタンは編集フォームの外に置き、閲覧ゲストも表示を切り替えられる。
