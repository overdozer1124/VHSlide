- `src/style.css`：表示設定の見せ方と、編集ツールの高さを調整。
- 付箋、ノート、左右パネル切替、保存・発表・集合の直接操作は維持。サーバー・権限・保存形式・発表ルート・フィルタ仕様は変更していない。

## 縦の連動の保存範囲

`src/App.tsx` の `cloud.onDeck` と `src/cloud.ts` の適用処理では、クラウド作品の `linkedRows`・`rowSelections` は各端末の表示設定として保持される。共有作品の本文の設定ではない。ゲストが切り替えても他の参加者の表示を切り替えない。端末作品では作品データとともに保存される。今回この挙動は変更していない。

設定パネルには、この保存範囲を利用状況に応じて説明する。「ページのデザイン」へ移す案は採用せず、右側の独立した表示パネルとした。
