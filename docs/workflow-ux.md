# 0.38.1：操作の入口と画面の整理

2026-10-24。「学習・発表」に担当・比較・PDF・発表ルート・版・ごみ箱が混在し、ヘッダーの「発表する」と区別しにくかった点を改善する。

## 操作の配置

| やりたいこと         | 新しい入口                               | 動作                                                                                                                     |
| -------------------- | ---------------------------------------- | ------------------------------------------------------------------------------------------------------------------------ |
| 自分の担当を見る     | 全体マップ → フィルタ → 自分の担当を選択 | 現在のシートで編集できるスライドを選択。既存の行・列・個別選択と組み合わせて確認し、適用する。編集画面への適用設定も維持 |
| スライドを比較       | 全体マップ → 比較                        | 実際のサムネイルから2〜4枚を選び、比較表示へ。比較中は選択欄を隠して内容の表示領域を確保。「選び直す」で選択へ戻る       |
| PDFを保存            | 保存の隣の▼ → PDFで保存                  | フィルタ中ならその範囲、それ以外は現在のシートを初期選択。サムネイルで調整して準備・印刷へ進む                           |
| JSONを保存           | 保存ボタン                               | 従来のワンクリック保存を維持。▼にも保存形式と用途を明記                                                                  |
| ふつうに発表         | 発表する                                 | 従来の縦横発表を直接開始                                                                                                 |
| 決めた順番で発表     | 発表するの隣の▼ → 保存済みルート名       | ルートを直接再生。「発表ルートを編集」から順番の作成・編集を行う                                                         |
| 版の保存・復元       | 保存の隣の▼ → 保存した版                 | 専用の履歴画面。ごみ箱や発表の操作を混在させない                                                                         |
| 作品をごみ箱から戻す | クラウド → 作品一覧 → ごみ箱を開く       | クラウド作品の管理画面で扱う。削除確認の案内文もこの入口へ変更                                                           |

ヘッダーの「学習・発表」と「自分の担当」は廃止。用途が異なる画面をタブ切り替えで同居させず、目的に応じた題名・説明・操作だけを持つダイアログを開く。

## 選択・表示・操作

- 長いボタンの縦一覧を、内容の見えるサムネイルの格子へ変更。選択状態と選択順をカードに表示し、発表ルートを選んだ順に作成する。
- サムネイルはスクロール領域の近くにあるものだけ描画し、1000枚のすべてをCanvas表示しない。チェックボックスによる選択は維持。
- メニューはクリック・タップ・矢印キー・Home/End・Enter・Escapeで操作でき、外側クリックやフォーカス移動で閉じる。ダイアログを閉じたら元の入口にフォーカスを戻す。
- ダイアログを画面中央に配置し、高さを制限。比較結果では選択用のUIを畳んでスライドを大きく表示する。
- 重複して表示されていた現在のページ番号の接頭辞をラベル内で整理。スライド本文・タイトルそのものは変更しない。
- 保存・発表の主ボタンの意味は変えない。タッチ環境の▼ボタンは幅44pxを確保する。

## 互換性と検証
