# 情報の構造化（第3段階、0.43.0）

0.43.1で右の設定を「見た目・配置・リンク」に整理しました。ページへのリンクは「リンク」タブから設定します。[UI/UX見直し](editor-ux-review.md)。

## 操作

- **図解・グラフ**から「比較」「手順」「時系列」、または棒・折れ線・円グラフを選ぶ。別々のタブと目的の説明を付け、常時表示のツールバーは増段しない。
- Shiftクリックまたは「まとめて選択」で要素を選び、右の**グループにする**を押す。以後は一緒に移動・複製・整列・重なり順変更できる。選択全体の右下で比率を保って拡大縮小。文字のサイズは従来の要素サイズ変更同様、別に設定する。
- グループ内の要素をダブルクリック／Enter／F2で選び、文字や個別の設定を編集する。「グループ全体を選択」で戻れる。解除後はクリックで1つを選び直せる。
- 線の両端の丸を図形・文字・画像・表・グラフの辺の中央へ近づけると接続する。右の**図形につなぐ**で相手と辺を指定する方法もある。相手の移動・サイズ変更・90度回転・反転に追従する。線だけ動かすと外部の相手から外れる。相手を削除した場合は線をその位置に残す。
- グラフは右側でタイトル、種類、項目名、値、色、値の表示、凡例を編集。最大12項目、1系列。棒・折れ線は負数に対応し、円は非負値のみ。合計0は空の円を表示。Excel・Google Sheets接続や複数系列・軸の高度な設定は今回の対象外。
- 要素を1つ選び、**ページへのリンク → 移動先を選ぶ**から同一作品内のシート・ページを選択。スライド上の「リンク先へ」で移動。発表中には「リンク元へ戻る」が上部操作に出る。リンク先が編集画面のフィルタ対象外なら、通知して編集用フィルタのみ外す。全体マップのフィルタは残る。

## 保存・参照・同期

- `model.ts`のJSON version 1に任意の`groupId`、`startAnchor/endAnchor`、`link.slideId`、`type: chart`を追加。古いJSONを引き続き読み込める。新しいオブジェクト入りのファイルを古いアプリで読み込むことは保証しない。
- `structureData.ts`で同一スライド内の線以外の要素だけを接続先として解決。線同士・自己参照を拒否。削除や同時編集で参照が欠損しても、保存した線端位置で描画する。外部URLをリンクとして実行しない。別作品の参照先を取得するAPIもない。
- グループはネストしない平坦な単位。グループ化時は最前の選択要素の位置で連続したレイヤーにまとめる。全体の配置ではグループを1単位として扱い、中に入った要素の重なり順変更はそのグループ内に留める。
- `copyElements/copyPages`で要素・グループ・グラフ項目を再ID化。コピー範囲内の接続とページリンクをコピー先へ付け替え、外部の接続はその時点の位置で切り離す。同一作品のコピー範囲外へのページリンクは維持。ページ、行、シートの複製にも適用。
- `sharedDeck.ts`のグラフは項目IDごとのY.Mapで保持し、異なる項目や異なる属性の変更を独立して同期する。同一項目の同じ属性はYjsの競合解決に従う。共同削除で全項目がなくなった状態も保持し、項目追加で再開できる。最大数や円の負数条件に反する競合更新は従来通りサーバー検証の対象。
- グループID・接続先・リンクは要素属性として同期。複数端末で同時に異なるグループ構成を変更した際の意味的な競合を自動統合する機能ではない。
- NodeとCloudflareは共通のモデル・認可処理を使用。編集範囲・本人Undo・安定した行列IDは維持。共同編集プロトコルを5へ更新し、直前の4を含む古いクライアントの更新を拒否する。ZIP version 1、バックアップの最終リビジョン検証、復元ジョブは変更しない。
- 描画はローカルのReact/SVGで、グラフの値を外部サービスへ送信しない。Canvasの共通描画をマップ、発表、印刷・PDFで使用する。PDF中のクリック可能なリンク注釈は生成しない。

### 残る確認・制約

- 実Chromebookの指操作・低メモリ時の応答、Windows実タッチパッド、iPad Safariは未検証。Chromiumの端末サイズ変更・合成タッチ／wheel試験と区別する。
- 1000枚すべてに大きい図解やグラフを入れた場合の描画時間・メモリは未測定。今回の試験は容量上限の負荷試験ではない。
- グループは平坦、図解は固定の初期配置から自由に編集する方式。ノード増減に伴う図解の自動レイアウト、接続線の障害物回避、複数系列グラフは未実装。
- 同じ属性の同時更新や同時グループ構成変更の利用者意図をすべて保存する保証はない。無効なグラフ状態になる更新はサーバー側で拒否する。
- 作品内リンクは同一作品に限定。対象外ページへの移動時には編集用フィルタを解除する通知を出す。PDF上ではリンクボタンを非表示にする。
