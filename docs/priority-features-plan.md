# 0.38.0 実装計画（2026-10-24）

対象は、自分の担当へジャンプ、ごみ箱と過去の版、発表ルート、比較表示、PDF保存。

- 担当移動：既存の安定した行・列IDと編集権限を使い、シートをまたいで自分の対象を一覧・選択・強調する。ホスト／全編集者は全スライドを対象とし、閲覧専用には担当なしと表示。
- 比較：全体／シート／現在のフィルタから選んだ最大4枚を独立した比較画面で表示。元スライドは変更しない。
- PDF：同じ範囲選択を使い、16:9・1スライド1ページの印刷画面とブラウザーのPDF保存を利用。画像とフォントを読み込んでから印刷可能にし、失敗画像は成功扱いにしない。
- 発表ルート：安定したスライドIDの配列と名前を作品に保存。複数シートを横断でき、順番変更・削除・ルート発表を提供。JSON・Yjs・バックアップを通して保持し、クラウドでの編集はホストに限定。通常の縦横発表は維持。
- 版：手動保存、削除直前の自動保存、更新時に最大5分に1回の自動保存。クラウドは作品ごと、端末は共通履歴として最大10版・20MB。写真は既存の画像を参照し複製しない。付箋を含めて保存し、共有権限は戻さない。過去版は必ず別作品として復元。クラウドはホストだけが版を取得・復元できる。
- ごみ箱：クラウド作品を論理削除して他者からのアクセスと接続を停止。ホストが復帰または明示確認のうえ完全削除。自動的には完全削除しない。ごみ箱内も作品数・画像容量の上限に含める。削除したページ・シートは削除前の版から確認・別作品へ復元可能。

受け入れ条件：旧JSON互換、移動後も担当に追随、権限外の版／ごみ箱操作拒否、再起動後の版とごみ箱保持、版の保持上限、ルートの保存・順番・削除済みページの扱い、比較中の元作品維持、PDFのページ数・画像・範囲、Node／Cloudflareでの同等動作。

本番ルームで編集テストは行わない。公開は別途指示があるまで行わない。
