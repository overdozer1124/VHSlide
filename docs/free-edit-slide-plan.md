生徒が自由に編集できるスライド（仮称「自由編集スライド」）実装計画 v0.1

作成：2026-11-18、VHSlide開発（新）。ODNさんの発案（提案メモ ~/workspace/vhslide-student-edit-slide-idea.md）をもとに、現在の製品コード（本番 0.143.2）を確認して作成。実装の着手は ODN さんの判断待ち。

## 1. 目的

閲覧のみの生徒でも、先生が指定した1枚のスライドを土台に、通常のスライド編集と同じ操作で自分のスライドを作れるようにする。先生の元のスライドは変わらず、結果は生徒ごとに保存され、先生が一覧で確認できる。

## 2. 既にある仕組みとの違い（コード確認済み）

- ゲストのページ追加（guestPageCreation）：編集参加中のゲストが「共有された作品の中」に白紙ページを足す仕組み。ページは作品の一部になり全員に見える。先生のスライドを土台にできないし、自分の分だけを切り離して一覧化もできない。今回の提案とは目的が違う。
- ワークシート：定義＋生徒ごとの回答（値）を分けて保存し、先生が一覧する型が既にある。今回の提案はこの型に乗り、回答の中身が「入力欄の値」ではなく「スライド1枚そのもの」になる。
- 授業コンソールの「生徒のスライド」：生徒の回答をスライドに重ねて一覧・拡大する表示が既にある。先生側の一覧はここへ接続する。

## 3. 仕組みの設計

### 3.1 保存（ワークシートと同じ型）
- 定義（先生が作る）：対象のスライド1枚を指定して「生徒の編集用」を作る。定義には、開始時点の土台スライドの写し（スナップショット）と受付状態（下書き・受付中・終了）を持つ。
- 土台を写しにする理由：先生が後から元のスライドを直しても生徒の土台は変わらない。生徒の編集が元に影響することもない。
- 回答（生徒ごと）：土台の写しから始めた、その生徒のスライド1枚（要素の並びそのままの JSON）。ワークシートの回答と同じく「定義 × 生徒」で1件、自動保存。
- 人数・容量の上限はワークシートと同水準（回答は500人まで等）を起点にし、1件あたりの上限は写真の扱いと合わせて段階1で決める。

### 3.2 生徒側の操作
- 受付中の間、対象スライドを開いた生徒に「自分のスライドを作る／続きを編集する」ボタンが出る（閲覧のみの生徒にも出る）。
- 編集画面は1枚だけの編集に絞る：既存の編集部品（キャンバス、文字・図形・画像・手描き、配置）を流用し、ページの追加・削除や他のスライドへの移動は出さない。
- 保存は自動。閉じれば下書きとして残り、受付が終わるまで何度でも直せる。

### 3.3 先生側の操作
- スライドを指定して編集用を作成 → 受付開始／終了（ワークシートと同じ操作感）。
- 結果は授業コンソールの「生徒のスライド」に並ぶ（生徒ごとのサムネイル → 拡大）。未作成の生徒も分かる表示にする。

### 3.4 権限と安全
- 生徒が読み書きできるのは自分の分だけ（サーバー側で強制）。他人のスライドは生徒同士では見えない。みんなに見せるのは先生経由（段階2の共有・集合）だけ。
- 先生のスライド本体と作品の保存には一切触れない（回答側の保存だけ）。

## 4. 段階分け

### 段階1（土台）：作れる・集まる・一覧できる
- 定義の作成（土台＝先生のスライドの写し）、受付状態の管理
- 生徒の1枚編集画面（個人のみ）と自動保存
- 授業コンソールでの一覧・拡大
- 受け入れ条件：閲覧のみの生徒が土台から自分のスライドを作って保存でき、先生の一覧に全員分が並ぶこと。先生の元のスライドが変わらないこと。他人の分が開けないこと。

### 段階2（活用）：見せる・返す
- よい作品を選んで回答スライド共有に出す、集合（フォロー）で見せる
- フィードバックと差し戻し（生徒入力計画 4.3）との接続
- 受け入れ条件：先生が選んだ生徒のスライドを、そのまま共有・集合で提示できること。

### 段階3（任意・必要なら）：広げる
- 班で1枚を共同編集（同時編集の競合処理が要るため別段階）
- 土台の選択肢（白紙から始める）

## 5. 容量への配慮

- 写真を貼ると1件が重くなる。写真は既存の写真保存の仕組み（重複排除あり、0.143.1）に乗せ、スライドの JSON には参照だけを持たせる方針を段階1で確認する。
- クラス全員分（例：40人×数MB）の見積もりを段階1の最初に出し、上限の扱い（超えたら保存時に理由を表示する等、既存の流儀に合わせる）を決める。

## 6. 既存計画との位置づけ

- 生徒入力拡張計画（PR #11）の段階3b・3cが進行中。**順序は決定済み（2026-11-18）：3b・3c → 段階4 → 本計画（新しい段階）。**
- 計画の前提（回答はスライド本体と別に生徒ごとに保存）には反しない。

2. 土台：**決定（2026-11-18）＝先生のスライドの写しのみ。** 白紙スタートは段階3（任意）のまま。
