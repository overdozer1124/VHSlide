# 第2段階：写真・文章・表（0.42.0）

0.43.1で設定の導線を整理しました。表は「見た目 → セル／表全体」、全体配置は「配置」へ移動しています。[UI/UX見直し](editor-ux-review.md)。

## 操作とUI

挿入ツールバーを増段せず、選んだ内容に必要な操作を右側へ表示する。文章では「選択した文字」と「ボックス全体の基本書式」を区別し、範囲選択中は全体設定を折りたたむ。表では選択セルを先に表示し、表全体の設定と位置ごとの行列操作を展開式に分けた。

### 画像

- 「切り抜き・位置調整」で独立したプレビューを開き、ドラッグ／タッチまたは位置スライダーで調整。拡大率100〜400%、現在の枠・正方形・4:3・16:9から選ぶ。回転済みの画像は元の向きで調整し、スライドでは既存の回転・反転を反映する。
- 適用までは作品を変更しない。キャンセル・Escで元に戻る。適用は1回の作品変更。
- 差し替えは既存の要素ID・位置・大きさ・代替テキストを保持し、元画像に合った中央の切り抜きへ初期化。非同期の読み込み中に元画像が変更・削除された場合は上書きしない。クラウド作品を切り替えた場合も追加を拒否する。
- 代替テキストは最大500文字。画像の説明は自動でアカウント名やファイル名から作らない。
- **切り抜きは隠蔽・匿名化ではない。** 元画像は保持され、共有先や完全バックアップにも含まれる。この点を切り抜き画面に表示する。個人情報を除去する用途では、事前に画像そのものを加工してから追加する必要がある。
- ファイル形式・6MB制限・非公開画像の参照制限は従来どおり。画像圧縮、未参照画像の容量回収、任意形状のマスクは今回の対象外。

### 文章

- 選んだ文字に太字・斜体・下線・取り消し線、文字色・背景色、サイズ12〜120px、読みやすい文字／明朝／等幅の書体を設定する。範囲未選択時はこれから入力する文字へ適用。
- 選択段落に左右・中央・両端揃え、箇条書き・番号付きリスト、行間1・1.25・1.5・2倍を設定できる。
- ボックス全体の基本書式も残す。全体の大きさ・太字・色等を変える操作では部分書式の該当項目も更新する。上下揃えはボックス内の配置として維持する。
- 内容は引き続きキャンバスで直接入力。Esc／Ctrl+Enterで終了。Ctrl/Cmd+Zとやり直しは既存の本人Undoへ接続する。貼り付けはプレーンテキストとして受け取り、外部HTML・リンク・埋め込みを持ち込まない。
- ローカル／共同編集とも同じQuillエディタを使い、画面を開いた後の編集開始が追加チャンクの取得に依存しない構成にした。初期JSにはエディタ分が加わるため、低性能端末での起動時間は実機確認が必要。

### 表

- セルをクリックして直接入力。Shiftクリックで四角い範囲を選択。タッチでは「セルの範囲を選ぶ」をオンにし、始点・終点をタップしてから終了する。
- 選択セルの背景色・文字色・サイズ・太字・斜体・左右／上下揃え・書式リセット。
- 選択位置の上下に行、左右に列を挿入できる。選択位置の行・列を削除でき、内容がある場合は確認する。既存の末尾追加／削除も表全体の設定に残す。
- 選択列の幅・行の高さを比率で調整し、均等に戻すことができる。寸法は固定の表の枠内で配分し、スライド外へ表を拡張しない。
- Excel等からTSVの複数セルを貼り付けると必要な行列を自動追加。範囲選択時はその左上を起点にする。範囲モードでのDelete／Backspaceは選択セルの内容だけを消し、表そのものを削除しない。モーダルや別の入力欄の操作には割り込まない。引用符内の改行も扱う。12×12やセル2000文字の上限を超える場合は全体を拒否し、既存セルを部分的に上書きしない。
- セル結合・表計算式・セル内の部分書式・行列境界のドラッグによる寸法変更は未実装。行・列の同時構造変更は従来のY.Mapによる配列の競合解決を使用し、複数人の構造変更の意図をすべて保存する保証はない。

## データと共同編集

- JSON／ZIP version 1を維持。`model.ts` は旧データを読み、新しい任意フィールドを検査する。`docs/deck.schema.json`も更新。
- 画像：`crop: {x,y,w,h}`は元画像に対する正規化範囲。`altText`は説明。元ファイルは変更しない。
- 文章：`text`にプレーン文字列を残し、`richText`にinsertのみの安全なDeltaを保存する。全文は`text + 最終改行`と一致させる。許可した書式のみを受け付け、HTML・URL・画像等の埋め込みや任意CSSを拒否する。同じ属性の隣接した部分は正規化して、保存／復元時のDeltaの区切り方に依存しない比較にする。
- Yjsでは文字と書式を同じY.Textに保存。旧文字を最初に編集するときも既存の文字の識別子を保持する。同時に旧ボックスを開いた場合の重複終端を識別・正規化し、余分な空行を表示しない。移行操作は本人Undoへ入れない。UTF-16の差分が絵文字のサロゲートペアを分断しないようにした。
- 表：セル書式は`styles[行ID:列ID]`、寸法は`widths[列ID]`／`heights[行ID]`。Yjsの既存の表マップへ項目ごとの安定キーとして保存し、別のセル・別の書式項目への同時変更を丸ごと上書きしない。行列挿入・削除で生き残ったIDの文字・書式・寸法を維持する。
- 共同編集プロトコルを4に更新。Node／Cloudflare双方で旧プロトコル3の書き込みを拒否する。古い画面は再読み込みが必要。新データを旧アプリで開く前方互換性は保証しない。
- 安定したスライド行列ID、範囲別権限、招待承認、画像の公開範囲、バックアップのリビジョン確認・冪等復元ジョブは維持する。実装・検証時点では本番へ未反映としていたが、ユーザーの指示により2026-10-25に0.42.0を公開した。

## 保持した制約

非ホストは未参照になったクラウド画像を再利用できない、従来の保護を緩めていない。そのため、画像差し替え後に元画像が未参照となった場合、クライアントのUndoによる画像復帰が拒否される場合がある。ホストによる履歴・バックアップからの復元を使う。切り抜きや代替テキストだけのUndoは画像参照を変えない。

同じ文字範囲の同じ書式や同じセルの同じ書式項目を同時に変更した場合には、CRDTの競合解決で一つの値になる。全員の異なる意図を同時に見た目へ反映する保証ではない。

従来のUI試験は、明示した「ボックス全体」「表全体」の展開操作と正確なラベル指定に更新した。試験データを変えて機能不良を隠したものではない。静的preview試験のAPI接続失敗ログは、クラウドAPIを起動しないオフライン相当の確認によるもの。クラウド機能は別サーバーで検証した。

範囲モードの最終試験では、サインアウトしたAPI応答をローカルにモックしてクラウドのモーダルを表示した。この試験は外部への接続の証拠ではない。IMEについてはcompositionフラグ付きイベントを確認しただけで、実機の日本語入力を検証したものではない。
