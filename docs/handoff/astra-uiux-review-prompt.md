最初に `docs/handoff/astra-uiux-review.md` を読んでください。引き継ぎZIPを受け取った場合は、新しいフォルダへ展開し、その中の `REVIEW_START_HERE.md` と `REVIEW-SNAPSHOT.json` で対象を確認してください。対象は0.43.1です。最新版には未コミット・未追跡ファイルが多数あるため、GitHubのmainやHEADだけを見て同じ実装だと判断しないでください。レビュー対象ファイルを照合できない場合は、その制限を明記してください。

今回はレビューのみです。アプリのソース、設定、バージョン、依存関係、データを変更せず、リファクタリング・機能追加・デプロイ・Gitのコミットやpushも行わないでください。通常開発では自動デプロイする運用ですが、このレビュー依頼ではデプロイ禁止を優先します。

公開URLは https://vhslide.overdozer1124.workers.dev/ です。公開された共有ルーム・生徒の作品にはアクセスせず、ログイン・参加申請・招待・作品作成など、本番へ書き込む操作もしないでください。編集・共同編集の検証はローカルの独立したサンプルとテストサーバーで行ってください。

この製品の中心は、自由配置のホワイトボードではなく、行・列に沿った2次元スライドの共同制作です。Googleスライドの外見を模倣することや、機能数を増やすことを目的にせず、この製品で自然に「考える・つくる・見比べる・発表する」ための操作を評価してください。

画面と実際の操作を確認し、全体マップ、編集、文字・画像・表・図形・グラフ・グループ・接続線、ズームとピンチ、サムネイルの移動、フィルタ、シート、共有権限・参加承認、付箋、保存・復旧、発表までの一連の体験を横断して評価してください。表の矢印やサイドバーだけに範囲を限定しないでください。

過去の改修記録を正解とせず、良い点も悪い点も再検証してください。特に「実装されている」と「初見で発見して正しく使える」を区別してください。好みだけの見た目の指摘より、操作の迷い、誤操作、過剰な手順、モードの分かりにくさ、編集領域の圧迫、フィードバック不足を優先してください。
