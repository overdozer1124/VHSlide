## 採用した仕様

- 強制フィルタはユーザー確認により通常UIの表示制御とする。Yjsの全データは端末に届き、開発者ツールやキャッシュからの取得を防ぐ仕組みではない。
- ホストの「ゲストの表示」設定を作品に保存し、権限のあるページのみの表示と全員分表示を切り替える。設定変更はサーバー側でもホストのみ許可。制限中はゲストによるフィルタ解除、他ページへの作品内リンク、全体JSON出力・全体コピーからの参照を抑制する。JSON出力は担当ページのみ。
- 新しい表示制御は更新版のブラウザに適用される。授業開始前に全員が再読み込みする。
- URLリンクはオブジェクト単位。選択文字列の一部分へのリンクではない。作品内リンクは既存のスライドIDを利用。
- 手描きは透明背景のPNG。保存後の線単位の再編集や消しゴムは対象外。キャンセルではスライドを変更しない。
- 縦書きはテキストボックス単位の vertical-rl。横書きの既存データはそのまま。日本語IMEと実ペンは実機で確認が必要。
