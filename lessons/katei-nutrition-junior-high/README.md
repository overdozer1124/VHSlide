# 授業スライド「4 中学生に必要な栄養」（家庭分野 2編1章・第4時）

指導書（p.36〜37）の学習の流れに沿った VHSlide 用の作品JSONです。

- `中学生に必要な栄養.vhslide.json`：VHSlide の「ファイル → 開く」で読み込みます。
- `src/`：JSONを作り直すスクリプト（`node deck.mjs out.json`）と、図1・キャラクターの画像（`node figs.mjs`）。
- `preview-*.png`：発表画面の見本。

## 構成（行＝学習の流れ、列＝その中の順番）

| 行 | 内容 | ワークシート入力欄 |
| --- | --- | --- |
| 導入（10分） | 表紙・学習目標／レッツスタート／学習課題 | q1 小学生の頃と比べた食事の変化 |
| 図1 体の成長 | 図1（身長・体重・1年の伸び）／解説：体をつくる栄養素 | q2 図1から読み取れること |
| 表1 食事摂取基準 | 表1／問い：読み取り／問い：大人と比べる／グラフ：カルシウム／解説：中学生に多く必要な栄養素 | q3 表1から読み取れること、q4 大人より多い栄養素（複数選択＋理由・集計公開） |
| 資料 スポーツと栄養 | 図2 運動とエネルギー消費量／解説・プロに聞く（要約） | q5 スポーツをする人の食事のポイント |
| まとめ（10分） | まとめよう／ふり返り／板書／ワークシート全体 | q6 必要な栄養素と理由、q7 自分の食事のふり返り（単一選択＋理由）、q8 これから気をつけたいこと |

発表ルート「授業の流れ（50分）」も入っています。各ページの発表者ノートに、指導書の指導のポイント・留意点を入れています。

## ワークシートの使い方

入力欄は1つのワークシート「中学生に必要な栄養 ワークシート」に属しています。JSONを開いたあと **クラウドに保存** すると、ワークシートが新しい作品に自動で登録・公開され、生徒は各自のアカウントで各ページの入力欄に回答できます。端末保存のままでは入力欄はプレビュー表示です。この機能はワークシート機能を含む版（0.85.0以降）の VHSlide が必要です。

## 確認してほしい点

- 表1の数値は指導書の画像から読み取ったものです（日本人の食事摂取基準2025年版）。授業前に教科書の表1と照合してください。
- 図1は文部科学省「学校保健統計調査」（令和4年度）の平均値をもとにした参考図です（数値は概数）。
- 「プロに聞く！」は教科書記事の要約です。人物名は載せていません。
