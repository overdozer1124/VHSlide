# 授業スライド「走れメロス」（国語2年・太宰治／全7時間）

先生の作成したスライド（PDF・26ページ）を、VHSlide で使える授業スライドに作り直したものです。スキル `vhslide-lesson` で生成しました。

- `走れメロス.vhslide.json`：「ファイル → 開く」で読み込み、**クラウドに保存** すると入力欄が使えます（1時間ごとに1つのワークシート、全7つ）。
- `make-spec.py` → `meros.spec.json`：レッスン仕様を作るスクリプト。`python3 make-spec.py` のあと `node .claude/skills/vhslide-lesson/scripts/build-deck.mjs meros.spec.json 走れメロス.vhslide.json` で作り直せます。
- `src/assets/`：原本PDFから取り出した挿絵（表紙の背景、人物相関図、夕焼けの場面、王様・メロスの絵など）。
- `preview-*.png`：全ページの見本。

配置：1行＝1時間（7行）／トーン：ギリシャ（羊皮紙・雷文・円柱）／キャラクター：本

## 原本から引き継いでいないもの
- 共同編集用リンク（1-1〜3-8、模擬授業1〜4）、参考BOXの音声データ・全文シート・学び合いリンクのURL。学校のアカウントのリンクのため入れていません。必要なら授業前に文字ボックスへリンクを設定してください。
- 原本の挿絵は、先生が使用許可を確認済みの素材として使っています。
