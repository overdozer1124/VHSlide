# 防災ポーチ＆サコッシュをつくろう（家庭分野・布を用いた製作）

製作キットの説明書（PDF）から作成。ボックス＋まる、手順マップで各自のペースで進む形（phase-grid、1シート）。

- 1行目：はじめに（目的の問い、完成のイメージ、材料表、ルーブリック）
- 2行目：手順マップ（各工程へのリンクと完了チェック）、製作計画表（回ごとの目標とふり返り）
- 以下、工程ごとに1行（地直し、1〜12、ミシン縫いのきほん）、最後にふり返り。全ページ右上に「手順マップへ」
- 図は説明書の図を切り出したもの（`src/`）。`make-spec.py` → `bousai.spec.json` → build-deck.mjs
