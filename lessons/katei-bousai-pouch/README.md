# 防災ポーチ＆サコッシュをつくろう（家庭分野・布を用いた製作）

製作キットの説明書（PDF）から作成。ボックス＋まる、手順マップで各自のペースで進む形（phase-grid、1シート）。

- 1行目：はじめに（目的の問い、完成のイメージ、材料表、ルーブリック）
- 2行目：手順マップ（各工程へのリンクと完了チェック）、製作計画表（回ごとの目標とふり返り）
- 以下、工程ごとに1行（地直し、1〜12、ミシン縫いのきほん）、最後にふり返り。全ページ右上に「手順マップへ」
- 図は説明書の内容をもとに描き直したもの（`figures.py` → `src/redesign/*.svg` → `node render-figures.mjs` で PNG）。色：本体の布＝青（表）・灰青（裏）、平ひも＝灰、ポケット＝淡い黄、縫う線＝マゼンタの破線、印＝青の点線。寸法は測る2つの端から補助線を出して示す。各ページは図＋「注意！」1行、手順の全文は発表者ノート。元の切り出し図は `src/*.jpg`。
-`make-spec.py` → `bousai.spec.json` → build-deck.mjs
