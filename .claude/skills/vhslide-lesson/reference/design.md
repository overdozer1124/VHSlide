# デザインとトーン

## プリセット

| テーマ | 印象 | 見出し | カード | 向く場面 |
| --- | --- | --- | --- | --- |
| `natural` | 落ち着いた緑×オレンジ | 濃色の帯 | 左に色帯 | 家庭・保健・生活全般 |
| `pop` | 明るい青×ピンク×黄 | 左のタブ | 淡い塗り | 小学校・導入・行事 |
| `chic` | 紺×金、余白多め | 下線 | 細い枠 | 高学年・中高の講義、社会・国語 |
| `chalk` | 黒板の緑×チョークの黄 | 黒板 | 枠 | 板書の延長として使う授業 |
| `wa` | 生成り×藍×朱 | 藍の帯 | 左に色帯 | 和服・伝統文化・国語の古典 |
| `shokutaku` | 生成り×トマト×菜っ葉 | 赤い帯＋ギンガムチェック | 淡い塗り | 食生活・調理など、食事が楽しくなる雰囲気にしたい時 |
| `minimal` | 白×アクセント1色 | 細い罫線 | 淡い塗り | 情報・数学、資料を主役にしたい時 |

トーンの指定が言葉だけ（例：「やわらかく」「シャープに」「学校カラーの紺で」）のときは、近いプリセットを `base` にして色だけ上書きしたテーマJSONを作る。

## Claude Design との連携

Claude Design（Artifact の Design / Design System 型）は、HTML のアートボードでデザインを作る道具で、VHSlide のJSONを直接は出力しない。次の2つの使い方で取り込む。

1. **デザインシステムから色を取り込む**：利用者が Claude Design で作ったデザインシステム（またはスライドの見本デザイン）のリンクや書き出したファイルを渡したら、読める手段（Claude Code では `Artifact` の `read`、それ以外では共有された内容・画像）で読み、主要色・背景色・文字色・強調色を取り出して、テーマJSON（`base` ＋ 上書き）にする。見出しの型・カードの型は見本の雰囲気に最も近いものを選ぶ。
2. **見本デザインを先に作る**：利用者が「デザインから任せたい」と言ったら、Claude Design が使える環境（Claude Code の `Artifact` の `quickstart`（intent: design）など）で、16:9 の表紙・問い・解説の3枚の見本を作って見せ、合意した配色と型をテーマJSONに写す。VHSlide で表現できるのは、塗りの四角・角丸・円などの図形、文字（ゴシック／明朝／等幅）、画像、表、グラフ。グラデーション・影・自由なフォントは使えないので、見本もその範囲で作る。

どちらの場合も、最終的な配置は `build-deck.mjs` の型に従う。型にない構図が必要なら `custom` で要素を直接書くか、`build-deck.mjs` に種類を追加する。

## 見た目の原則

- 1ページ1メッセージ。見出しは名詞句より「問い」か「結論」にする（例：「カルシウムが一番必要なのはいつ？」）。
- 強調色（accent）は「問い」と「強調すべき数値」にだけ使う。グラフは `highlight` で注目点だけ強調色、他は `muted`。
- 文字は本文19〜22pt、補足14〜17pt、出典12pt。12pt未満は不可（VHSlide の制約）。
- 入力欄は白地＋強調色の枠で、どのテーマでも「ここに書く」と分かるようにする。
- キャラクターは各ページに最大1体。問いのページは「?」、解説・グラフの気付きは「!」、表紙は「♪」。

## VHSlide の制約（ビルドで自動チェック）

- 要素はページ内（x+w ≤ 960、y+h ≤ 540）、幅・高さ20px以上。細い線は「太い図形を背景色の図形で覆う」方法で描く。
- 色は `#rrggbb`。画像は png/jpeg/webp/gif のデータURL（SVG は PNG 化）。
- 大きな角丸図形は角が大きくなり文字が欠けやすい。文章は図形の中ではなく、背景図形の上の文字ボックスに置く（ビルドは自動でそうしている）。
- 枠線は図形の縦横比で太さが変わるため、均一な枠は「外側の色図形＋内側の塗り図形」で描く。
