# VHSlide の新しい機能と授業スライドでの使い方

最終確認：VHSlide 0.150.0（2026-11-19）。新しい版が出たら、`src/releaseHistory.ts` の先頭を読んでこの表に追記する。

## スキルが自動で使うもの

| 版 | 機能 | スキルでの扱い |
| --- | --- | --- |
| 0.101.0 | 書体9種（丸ゴシック・教科書風・手書き風・UDゴシック・筆文字・見出し明朝など。Webフォントなので生徒のChromebookでも同じ見た目） | テーマごとに見出しの書体（`headingFont`）と本文の書体（`font`）を設定。本文は全テーマ UDゴシック。文字ボックスの `richText` で指定する。`--no-fonts` で無効化 |
| 0.106.0 | 回答欄の「項目名（見出し）を表示しない」 | 入力欄に `hideLabel: true`。スライドの別の場所に問いを書いたときや、画像欄を広く使いたいときに |
| 0.106.4 | 画像・手描き欄のキャンバスが配置した枠の形に合う | 枠の高さの制約がなくなった。幅160・高さ120未満のときだけ警告 |
| 0.107.0 | 画像・手描き欄の「貼り付け前の案内文」 | 入力欄の `placeholder` がそのまま案内文になる（例：「調べた染織の写真を貼ろう」） |
| 0.149.0 | 選択式の入力欄で「選択肢を縦に並べる」 | `optionsVertical: true`。`quiz` の回答欄は自動でオン（大きな文字の選択肢が1行に1つずつ並ぶ） |
| 0.135.0 | 「自由入力（手描き＋文字）」入力欄 | `type: "free"`。図を描いて文字で補足する説明、作品の写真に工夫を書き込む記録などに。大きさは画像・手描き欄と同じ目安（幅160・高さ120以上） |
| 0.133.0〜0.134.0 | 「順番を選ぶ（並べ替え）」入力欄（2〜10項目。回答結果は「I → am → a → student」のように表示・CSV出力。自動の正誤判定はまだない）。並び替え前の表示を「ランダム」か「入力した順」から選べる | `type: "order"`、`options` に正しい順番で書く。`asListed: true` で入力した順のまま表示。語順・手順・時代の順・作業の段取りの確認に |
| 0.131.0 | 入力欄の見出しを左に置く（縦書きも可）、見出しを詰める | `labelLeft`・`labelVertical`・`labelCompact`。高さの低い欄（名前・日付・計画の1行欄）で書く場所を広げる |
| 0.123.0〜0.126.1 | スライドにWebアプリを埋め込む（URL、または自分で登録したアプリ）。生徒は自分の端末で操作する | form の `{type:"app", url, …}`（要素は `embed: {url}`）。シミュレーションや外部の教材を、スライドから出ずに使わせたいときに。自分のアプリの登録は先生がアプリ上で行う |
| 0.127.0 | 画像・手描き欄で画像を6枚まで自由に配置（移動・拡大縮小・重なり順） | 画像欄の使い道が広がった（調べた写真を並べて比べる、写真に書き込む）。JSON の変更は不要 |
| 0.130.0 | 画像・手描き欄のボタンを「ツール」に集約 | 小さめの画像欄でも描く場所が残る（それでも幅160・高さ120以上を推奨） |
| 0.109.0 | 回答欄で枠が狭くてもスクロールバーが出ず、「保存済み」の表示も出ない | 入力欄を小さめに置いても見た目が崩れにくい（目安：1行の欄は高さ58以上） |

## JSON では作れない・授業前に先生が操作するもの

| 版 | 機能 | 授業スライドでの勧め方 |
| --- | --- | --- |
| 0.110.0〜0.113.0 | みんなで書き込む「ウェビングマップ」、作品共通の「グループ（班）」、グループ別のマップ | マップはクラウド上で作る仕組みで、JSONのファイルからは引き継げない（フォームの引き継ぎはワークシートとアンケートのみ）。ウェビングをする授業では、スライドに場所（説明の枠）と画像・手描き欄の代替を用意し、発表者ノートに「授業前に フォーム →『ウェブマップ』で中心テーマを作り、このスライドに配置する」と書く |
| 0.144.0 | 「前の自分の回答」をスライドに表示（元のワークシートの項目・アンケート・点を置く思考ツールを選んで配置。本人の回答だけが見える） | クラウド上の項目を選んで置く部品なので JSON からは作れない。前の時間の予想や考えと比べさせたいページには、場所（枠）と説明を用意し、ノートに「授業前に『前の自分の回答』で第○時の○○を選んで、この枠に置く」と書く |
| 0.145.0 | 学びの記録の「回答状況」（生徒×時間の表で回答済み・未回答） | 時間ごとにワークシートを分けて作っている（スキルの既定）ので、そのまま時間ごとの回答状況として見られる |
| 0.146.0〜0.148.0, 0.150.0 | 思考ツールの生徒（班）ごとの表示、カードの言葉の分析、よいチャートを全員に大きく見せる、心情曲線（場面ごとの気持ちの変化を線で。登場人物ごとに最大3本） | 心情曲線は国語の物語文（登場人物の心情の変化）で特に有効。思考ツールと同じく JSON では作れないので、場所と準備の手順（例：「フォーム →『思考ツール』→ 心情曲線、場面＝…、登場人物＝…」）をノートに書く |
| 0.143.1 | 写真の保存容量を作成者ごと500MBに拡大、同じ写真は1回だけ数える。取り込めなかったときは理由も表示 | 大きな単元を何度クラウドに保存し直しても、同じ背景・キャラクターの画像は容量を増やさない |
| 0.143.2 | 「印刷・PDFで出力」 | 板書例やワークシート全体のページは、印刷して掲示・配布にも使える |
| 0.136.0〜0.141.0 | 思考ツール：位置型（座標軸・数直線・感情メーター・心情円。場面ごとに点が残り考えの変化が見える）と、区切り・カード型（ベン図・Y/X/W/Tチャート・PMI・マトリックス・KWL）。個人・班・全体で書き込め、結果は授業コンソールで区切りごと・生徒（班）ごとに見られる | ウェビングマップと同じく、クラウド上で先生が作って「受付を開始」してから配置するもので、JSON からは作れない。使う授業では、その場所（枠）と説明をスライドに用意し、発表者ノートに「授業前に フォーム →『思考ツール』で○○（例：Yチャート、区切り＝見た目・音・感じ）を作り、この枠に配置する」と書く |
| 0.121.0〜0.122.0 | 授業コンソールで記述回答の「言葉の分析」（よく出る言葉と人数、一緒に出る言葉、ワードクラウド）。解析は先生の端末の中で行う | 全員の考えの傾向を見たい問いは、選択式にせず記述（text）にしてよい。ノートに「授業コンソールの言葉の分析で、よく出た言葉を全体に紹介する」と書く |
| 0.129.0 | 集合を解除しても、生徒は集合したスライドに留まる | 一斉→個別へ切り替える場面（自由進度の第1時など）で、集合で見せたページから各自が始められる |
| 0.132.0 | 全体マップに「いまのページ」のバッジとボタン | 自由進度学習で子供が自分の位置を確かめやすくなった（学習マップのページと併用） |
| 0.125.0 | 作品のファイルサイズ表示（保存上限25MB） | クラウドの上限とは別に、開いている作品は**ブラウザーの保存領域（1サイトで約5MB、1文字＝2バイト）に自動保存**され、超えると「端末の保存容量が不足」と出る。作品のファイルは2MB（約200万文字）以内を目安にする。背景の装飾は WebP で小さく作る（スキルが自動で行う）。図は PNG の減色（64色程度）か WebP にし、長い単元は作品を分ける。ビルドは200万文字を超えると警告する |
| 0.102.0〜0.105.0, 0.114.0 | 授業コンソール（回答一覧・設問ごとの集計・生徒のスライド・回答スライドの共有） | 渡すときの案内に「授業中は授業コンソールで回答を確認・共有できる」と書く。集計公開の選択式（`public`）はコンソールの「設問ごとの集計」とも相性がよい |
| 0.113.0〜0.118.0 | コンソールのグループ別マップ、拡大表示、「集合で見せる」 | グループ活動のある授業では、班ごとの書き込みを全体に見せる場面を発表者ノートに書く |
| 0.115.0 | 集合中にホストが発表すると、生徒の画面がスライドだけの表示になり、スライド上の回答欄にはそのまま入力できる | 「全員を集合 → 発表する」で、投影と生徒の入力を同時に進められることを案内する |
| 0.116.0 | ワークシート同士で項目をコピー・統合（回答ごと統合も可） | 1ページだけのJSON（例：ワークシートを1枚にしたもの）を「JSONを追加」で足すと別のワークシートになるが、「設定・内容の確認 → 別のワークシートと統合」で1つにまとめられる、と案内する |
| 0.108.0 | 回答欄・ワークシートの項目を右のサイドバーで直接編集 | 授業前に問いの文言や選択肢を直したいときは、スライド上の回答欄を選んでサイドバーで直せる、と案内する |
| 0.119.0〜0.120.3 | 画像のダブルクリックでその場で切り抜き、画像・手描き欄の切り抜き | スキルの図は切り抜き不要だが、先生が教科書の写真などを差し替えるときに使える |
