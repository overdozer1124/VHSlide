# VHSlide の新しい機能と授業スライドでの使い方

最終確認：VHSlide 0.120.3（2026-11-14）。新しい版が出たら、`src/releaseHistory.ts` の先頭を読んでこの表に追記する。

## スキルが自動で使うもの

| 版 | 機能 | スキルでの扱い |
| --- | --- | --- |
| 0.101.0 | 書体9種（丸ゴシック・教科書風・手書き風・UDゴシック・筆文字・見出し明朝など。Webフォントなので生徒のChromebookでも同じ見た目） | テーマごとに見出しの書体（`headingFont`）と本文の書体（`font`）を設定。本文は全テーマ UDゴシック。文字ボックスの `richText` で指定する。`--no-fonts` で無効化 |
| 0.106.0 | 回答欄の「項目名（見出し）を表示しない」 | 入力欄に `hideLabel: true`。スライドの別の場所に問いを書いたときや、画像欄を広く使いたいときに |
| 0.106.4 | 画像・手描き欄のキャンバスが配置した枠の形に合う | 枠の高さの制約がなくなった。幅160・高さ120未満のときだけ警告 |
| 0.107.0 | 画像・手描き欄の「貼り付け前の案内文」 | 入力欄の `placeholder` がそのまま案内文になる（例：「調べた染織の写真を貼ろう」） |
| 0.109.0 | 回答欄で枠が狭くてもスクロールバーが出ず、「保存済み」の表示も出ない | 入力欄を小さめに置いても見た目が崩れにくい（目安：1行の欄は高さ58以上） |

## JSON では作れない・授業前に先生が操作するもの

| 版 | 機能 | 授業スライドでの勧め方 |
| --- | --- | --- |
| 0.110.0〜0.113.0 | みんなで書き込む「ウェビングマップ」、作品共通の「グループ（班）」、グループ別のマップ | マップはクラウド上で作る仕組みで、JSONのファイルからは引き継げない（フォームの引き継ぎはワークシートとアンケートのみ）。ウェビングをする授業では、スライドに場所（説明の枠）と画像・手描き欄の代替を用意し、発表者ノートに「授業前に フォーム →『ウェブマップ』で中心テーマを作り、このスライドに配置する」と書く |
| 0.102.0〜0.105.0, 0.114.0 | 授業コンソール（回答一覧・設問ごとの集計・生徒のスライド・回答スライドの共有） | 渡すときの案内に「授業中は授業コンソールで回答を確認・共有できる」と書く。集計公開の選択式（`public`）はコンソールの「設問ごとの集計」とも相性がよい |
| 0.113.0〜0.118.0 | コンソールのグループ別マップ、拡大表示、「集合で見せる」 | グループ活動のある授業では、班ごとの書き込みを全体に見せる場面を発表者ノートに書く |
| 0.115.0 | 集合中にホストが発表すると、生徒の画面がスライドだけの表示になり、スライド上の回答欄にはそのまま入力できる | 「全員を集合 → 発表する」で、投影と生徒の入力を同時に進められることを案内する |
| 0.116.0 | ワークシート同士で項目をコピー・統合（回答ごと統合も可） | 1ページだけのJSON（例：ワークシートを1枚にしたもの）を「JSONを追加」で足すと別のワークシートになるが、「設定・内容の確認 → 別のワークシートと統合」で1つにまとめられる、と案内する |
| 0.108.0 | 回答欄・ワークシートの項目を右のサイドバーで直接編集 | 授業前に問いの文言や選択肢を直したいときは、スライド上の回答欄を選んでサイドバーで直せる、と案内する |
| 0.119.0〜0.120.3 | 画像のダブルクリックでその場で切り抜き、画像・手描き欄の切り抜き | スキルの図は切り抜き不要だが、先生が教科書の写真などを差し替えるときに使える |
