# 授業スライドを設計する考え方

指導案をページに写すのではなく、**「この授業で、子供と先生がスライドをどう使うか」から形を決める**。決まった型に当てはめるのではなく、毎回次の順で考える。初めて見る授業の型でも、この考え方で組み立てられる。

## 1. 誰が、いつ、どう使うかを決める

まず指導案の「形態」（一斉・個別・グループ）、時数、場所、学習環境（掲示物・お助け動画・教具）を読み、スライドの使われ方を見極める。

| 使われ方 | 誰が操作する | スライドに必要なこと |
| --- | --- | --- |
| 先生が投影して一斉に進める | 先生 | 1本の流れ（発表ルート）、問い→解説の対、評価・留意点は発表者ノート |
| 子供が自分の端末で自分のペースで進める | 子供 | 迷わない動線（今どこ・次はどこ・戻り方）、選べる入口、記録する場所、進み具合が見えること |
| 一斉と個別が混ざる | 両方 | 一斉の場面と個別の場面を分けて置く（シートや行を分ける） |

子供が操作する授業では、**先生がそばにいなくても進められるか**が一番大事になる。

## 2. 授業の型を見極め、構造（シート・行・列）を決める

VHSlide は「シート」「行（上下）」「列（左右）」「リンク」「発表ルート」で構造を作れる。授業の型に合わせて選ぶ。

| 授業の型（指導案に出てくる言葉） | 構造の考え方 |
| --- | --- |
| 一斉授業（導入・展開・まとめ） | 1行＝1時間（lesson-rows）。左から右へ授業が進む。 |
| 単元内自由進度学習（マイプラン、学習マップ、ミッション、自分で計画） | シート＝教科、行＝ミッション。各教科の最初に「学習マップ」（ミッションへのリンクと完了チェック）、全ページに「学習マップへ」ボタン。共通シートに計画・振り返りの欄。発展（パワーアップ）やチェックテストも行にする。 |
| 複線型・選択課題（コース別、レベル別、選べる課題） | 分かれ道のページに選択ボタン（リンク）、コースごとに行を分け、最後に全員が集まるページへ合流させる。 |
| 探究・プロジェクト（課題設定→情報収集→整理・分析→まとめ・表現） | 段階ごとに行を分け、各段階に記録（写真や図が貼れる画像欄）とふり返りの欄。段階をまたいで見返せるよう、ワークシート全体のページを使う。 |
| 協働学習（グループ、ジグソー、話し合い） | 役割や資料ごとに行を分け、共有したい答えは選択式＋集計公開。話し合いの結果は授業コンソールで全体に見せる前提で作る。 |
| 製作・実習（調理、裁縫、工作、実験など。説明書・レシピ・手順書がもとになる） | 工程ごとに1行。2行目に「手順マップ」（各工程へのリンクと完了チェック）と、回ごとの目標・ふり返りの欄。全ページに「手順マップへ」。工程のページは描き直した図を大きく、下に「注意！」を1行。困ったとき用の基本操作（ミシン・包丁・火の扱いなど）も1行にする。完成作品は自由入力の欄（写真＋文字）で残す。例：`lessons/katei-bousai-pouch/` |
| 単発のワークシート・ふり返りシート | 1ページの form に入力欄を座標で配置する。 |

型がはっきりしないときや、どれにも当てはまらないときは、次の3つの問いから構造を決める。
- **子供は何を自分で決めるか**（順番・課題・速さ・方法）→ 決める場面には「選ぶページ」と「リンク」を作る。
- **何を記録に残すか**（考え、作品、計画、ふり返り）→ ワークシートの入力欄にする。時間をまたぐ記録は1つのワークシートにまとめる。
- **何を共有するか**（答え、意見、作品）→ 選択式＋集計公開、または授業コンソールで見せる。

## 3. 子供になったつもりで動線を描く

子供が操作する授業では、ページを作る前に、子供が1時間をどう過ごすかを頭の中でたどり、次の問いに全部答えられるようにする。

| 子供の問い | スライドでの答え方 |
| --- | --- |
| 今日は何をするの？ | 入口のページ（「今日はどこから始める？」）、毎時間の流れ |
| 今どこにいる？ 次はどこ？ | 学習マップ、行の名前（ミッション名）、見出しのラベル |
| 困ったらどうする？ | 各ページのヒント（教科書のページ、掲示物、お助け動画、場所） |
| 終わったら？ | 完了チェック、次のミッションや発展（パワーアップ）への案内 |
| 戻りたい | 「学習マップへ」などの戻るボタン |
| 自分はどこまで進んだ？ | 学習マップの完了チェック、ワークシート全体のページ |
| 計画がずれた | 計画と修正を書く欄（ずれても直せばよいと書き添える） |

一斉授業でも、生徒が自分の画面で入力する場面（集合→発表）があるので、問いのページには必ず入力欄を置く。

## 4. 先生の立場でも見直す

- 一斉で使う場面（第1時の説明、最後のまとめ）は、投影して見やすい大きさにする。
- 評価規準・評価の方法・指導の留意点・予想される反応は発表者ノートに入れる（子供の画面には出さない）。
- 授業中に確かめたいこと（全員の考え、進み具合、自己評価）は、ワークシートと集計公開で授業コンソールから見られるようにする。

## 5. 機能は「ねらい」から選ぶ

| ねらい | 使う機能 |
| --- | --- |
| 自分で順番を選ばせる | リンク（ボタン）、学習マップ、行の分け方 |
| 進み具合を見えるようにする | チェック欄（完了）、ワークシート全体のページ |
| 考えを残す・見返す | 入力欄（記述）、ワークシート（1時間や単元で1つ） |
| 作品・観察・作図を残す | 画像・手描きの欄（drawing）。写真や図に文字で説明を添えるなら自由入力（free） |
| 考えを整理・比べる（ベン図、Yチャート、座標軸、心情の変化） | 思考ツール（先生がクラウドで作って配置。スライドには場所と説明、ノートに準備手順） |
| 全員の考えを比べる | 選択式＋理由欄＋集計公開、授業コンソール |
| 見通しと自己評価 | ルーブリック（最初に見通し、最後に自己評価） |
| 順番のある手順 | steps、番号つきのページ。理解を確かめるなら並べ替えの入力欄（`order`） |
| 語順・手順・時代の順を答えさせる | 並べ替えの入力欄（`order`） |
| 全員の記述の傾向をつかむ | 記述の入力欄＋授業コンソールの「言葉の分析」 |
| 外部の教材・シミュレーションを使わせる | Webアプリの埋め込み（form の `app`） |
| 印象づける | statement（大きな数字・ひと言） |

## 6. 指導案の言葉を構造に置き換える（例）

| 指導案の言葉 | スライドでの形 |
| --- | --- |
| 学習マップ、ミッション一覧 | リンク付きのマップのページ＋完了チェック |
| ミッション○、課題○ | 1つの行（行名＝ミッション名） |
| パワーアップ、発展課題、チャレンジ | 発展の行（終わった子が選ぶ） |
| チェックテスト→自分で丸付け | テストの行＋直しを書く欄 |
| マイプランシート、学習計画 | 時間ごとの「計画」と「振り返り・修正」の欄 |
| 場所（教室・オープンスペース） | ヒントの欄に書く |
| 掲示物、お助け動画、トレーシングペーパー | ヒントの欄に「困ったら」として書く |
| 形態：一斉／個別 | 一斉の場面と個別の場面を分ける |
| 研究の重点・目指す児童像 | その重点を支える機能を目立たせる（例：計画の修正が重点なら、修正の欄を毎時間に） |

## 7. 教科の表記と、今どこかの分かりやすさ

- **国語で文章を読ませるページは縦書き**（`passage`）にする。本文・古文・詩・短歌・漢文の書き下しなど。説明・問い・入力欄・表は横書きのままでよい。
- **単元の中で、今日がどの時間かが直感で分かるようにする。** 全体で統一感を保ちつつ、時間ごとに色やキャラクターの色を変える（複数時間の作品ではスキルが自動で行う。`color` で変更可）。表紙は時間ごとに見分けがつくようにする。

## 8. よくある失敗

- **子供が自分で進める授業を、一斉授業と同じ1本道にしてしまう。** 全ページが1本の流れに並び、リンクも学習マップもないと、子供は順番を選べず、今どこにいるかも分からない。
- 複数の教科・単元を1つのシート・1つのワークシートに混ぜてしまう。
- 指導案の表や文章を、そのままスライドに貼り写してしまう（子供が使う形に置き換えていない）。
- 入力欄のない問いのページ、ヒントのない課題のページ。

## 9. 仕上げに1周する

できあがったら、**子供になったつもりで最初のページから1周たどり**、迷う場所・戻れない場所・何をすればよいか分からないページがないかを確かめる。続けて**先生になったつもりで**、一斉の場面の見やすさと、評価に必要な記録が残るかを確かめる。
